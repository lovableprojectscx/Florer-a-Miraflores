# Spec Kit — Florería Miraflores

Paquete de contexto estructurado (spec-driven) para que cualquier chat/modelo nuevo entienda el proyecto sin depender de la conversación anterior.

## Léelo en este orden

1. **`constitution.md`** — principios y reglas no negociables (stack, seguridad, convenciones, cómo trabajar).
2. **`spec.md`** — qué es el producto y qué hace (alcance, usuarios, flujos, features).
3. **`plan.md`** — cómo está construido (stack real, arquitectura, decisiones, divergencias).
4. **`tasks.md`** — qué falta, priorizado (lo que sigue).

## Documentación detallada (fuente de verdad ampliada)

Este spec kit es el resumen. El detalle vive en:
- `../CLAUDE.md` — especificación original completa.
- `../docs/` — REQUISITOS-FUNCIONALES, ARQUITECTURA, BASE-DE-DATOS, PLAN-DE-TRABAJO, ACTUALIZACIONES, INCIDENCIAS.
- `../brand/` — identidad visual, logo SVG y prompts de imágenes.
